# StyleRoute — Academic Project Page Template edition

Adapted from https://github.com/eliahuhorwitz/Academic-project-page-template (master).
Original template CSS is retained in `static/css/bulma.min.css` and `static/css/index.css`.
Project-specific styles are in `static/css/styleroute.css`; interactions are in `app.js`.
Template attribution is preserved in the footer. Template website license: CC BY-SA 4.0.
Paper figures/results remain the authors' research materials.

## GitHub Pages
Upload the contents of `dist/` to the root of a public project repository.
In Settings > Pages, select Deploy from a branch, main, /(root).
Keep `index.html`, `app.js`, `static/`, `.nojekyll` and `assets/` together.
No installation or build step is required.

Edit `index.html` for authors/text/results/citation. Replace
`assets/styleroute-paper.pdf` for a newer paper PDF.
